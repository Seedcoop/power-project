# POWER PROJECT

고등학생 모둠이 5개 분야의 설계안을 선택하며 발전소 설계 의사결정을 체험하는 웹앱입니다. 단일 HTML에 화면·계산 엔진·이미지·서체·WebGL 모델·SVG 대체 화면이 포함되어 있습니다.

실행 주소: **https://seedcoop.github.io/power-project/**

저장소: https://github.com/Seedcoop/power-project

2026-11-15 사용자 승인에 따라 공개 저장소에 업로드하고 GitHub Pages 배포를 완료했습니다. 게시 원본은 `main` 브랜치의 `/(root)`입니다. 게임 HTML은 준비본과 동일합니다. 자료별 공개 권한 근거의 별도 확인 상태는 [확인표](docs/PUBLICATION_REVIEW.md)에 유지합니다.

## 실행

1. 이 폴더의 `index.html`을 실제 웹 브라우저에서 엽니다. 브라우저에서 파일 실행이 가능한 환경에서는 인터넷 연결 없이 사용할 수 있습니다.
2. 정적 웹 서버에서도 같은 파일을 사용할 수 있습니다. 빌드 명령·패키지 설치·서버 프로그램은 게임 실행에 필요하지 않습니다.
3. iPad·Android에서는 사용한 브라우저와 파일 열기/URL 접속 방법을 기록하고 실기기로 확인하세요. 파일 미리보기 화면의 동작과 실제 Safari/Chrome 실행을 구분해야 합니다.

## 수업 진행

- 기본 설계팀 소개 → 실제 학생 4~6명 등록·합류 → 5단계 브리핑·단계별 설계안 4개 비교.
- 설계 반영 후 이전 선택을 바꾸지 않습니다. 1~4단계는 반영 완료 확인 → 통합 뉴스 → 교사 공통 코드 → 다음 단계입니다. 뉴스는 총 4회입니다.
- 5단계 완성 → 최종 코드 → 가상 시험 준비 → 사건 경고 약 3초 → 시험 연출 약 15초 → 결과입니다.
- 최종 사건 5종과 시험 1회 제한을 유지합니다. 장면 다시 보기는 저장된 사건·결과를 재생합니다.
- 기존 MASTER와 PowerEngine의 점수·직무 보정·성공 확률·패널티를 유지한 파일입니다.

공통 코드는 `POWER → SMR → IDPP → PLANT → KEPCO`입니다. 코드와 계산 규칙은 HTML에 포함되어 있습니다. 공통 코드는 수업 진행을 맞추는 용도이며 접근 권한을 인증하는 비밀값으로 취급하지 않습니다.

## 저장과 복원

진행 기록은 사용 중인 브라우저의 localStorage에 저장됩니다. 서버로 수집하는 기능은 포함하지 않았습니다. 자동 저장·중단 복원·장면 다시 보기 처리는 원본 그대로입니다.

- 저장 키: `power-project-v2-ratio-final-20261110` 및 관련 보조 키.
- 파일 실행에서 웹 주소로 이동하거나 브라우저·기기·접속 출처가 바뀌면 저장 기록이 자동 이전되지 않습니다.
- 같은 출처에서 같은 저장 키를 쓰는 복사본을 함께 운영할 때는 기록 공유 가능성을 점검하세요.
- 같은 기기에서 다음 팀이 사용할 때는 이전 결과를 확인·보관한 뒤 게임의 전체 초기화를 사용합니다.

저장 범위 참고: [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage).

## GitHub 등록 및 Pages 준비

이 폴더의 **내용**을 저장소 루트에 배치하면 됩니다. ZIP을 받았다면 압축을 먼저 풀고 파일을 올립니다.

- 코드 보관과 학생 접속용 웹 공개는 별도 결정입니다. Pages를 활성화하면 별도 웹 공개가 이루어집니다. 비공개 저장소라고 웹사이트도 자동 비공개인 것으로 판단하지 마세요.
- 공개 전 권한 확인이 끝나면 GitHub Pages의 게시 원본을 해당 브랜치의 `/(root)`로 지정하는 방법을 사용할 수 있습니다. `.nojekyll`은 정적 파일을 그대로 배포하기 위한 표식입니다. 이 파일 자체가 사이트를 공개하지는 않습니다.
- 자동 배포 워크플로·빌드 스크립트는 넣지 않았습니다. 기존 작업용 스크립트를 실행하여 확정 HTML을 다시 생성할 필요가 없습니다.
- 실제 배포 주소에서 새 팀 등록·저장·새로고침·코드·최종 시험·WebGL/SVG를 다시 확인합니다. 웹 접속형의 오프라인 동작은 별도 점검합니다.

공식 설정 안내: [GitHub Pages 게시 원본](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

기준본의 데스크톱 Edge 검사에는 태블릿 화면 크기 10종, 화면 220개, 실제 선택 200개, 최종 시험 20개 전체 재생과 전체 5단계 진행이 포함됩니다. [검증 요약](docs/VALIDATION.md)을 확인하세요. 이 기록은 실제 iPad Safari·Android Chrome 검사와 구분합니다.

**실기기, 실제 모바일 주소창·키보드·안전 영역·OS 앱 전환·GPU 성능은 미검증입니다.** 공개 수업 전에 별도 실기기 검증이 필요합니다.
